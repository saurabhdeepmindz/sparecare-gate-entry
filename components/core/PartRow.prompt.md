One-line: a part-search result line; use several in sequence inside a card, not standalone.

```jsx
<PartRow name="Front brake pad set" fitment="Fits Maruti Swift 2018–22"
  partNumber="BP-2291-FR" availability="Held at 6 nearby stores" tone="ok" statusLabel="In stock" />
```

Rows are separated by a 1px rule; set `last` on the final row to drop it. The part number is the one place mono type is correct. Write `availability` as a sentence a counter clerk would say — "None nearby — request transfer", not "0 results".
