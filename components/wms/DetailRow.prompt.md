One-line: a carried-forward read-only value at the top of a handheld screen.

```jsx
<DetailRow icon="file-text" label="Gate Entry Number" value="GEN-000845" mono />
<DetailRow icon="building-2" label="Supplier" value="ABC Supplies Pvt. Ltd." last />
```

Use for context the operator needs but cannot change. Anything editable belongs in a `Field` instead.
