One-line: the WMS single-line input, sized for a gloved thumb on a rugged terminal.

```jsx
<TextInput placeholder="Enter Person's Name" />
<TextInput readOnly value="12 Aug 2026, 09:40" />
```

Never drop below the 44px minimum height. `readOnly` is the correct treatment for anything the system fills in — it is visually distinct from an empty optional field, which matters because the FRD separates system-captured from dealer-configurable mandatory fields.
